## Checklist do que o vídeo DEVE mostrar

1. Privacidade / “cada conta é isolada”  
2. Início: Favoritos · Mapa · Serviços · Banco  
3. Categorias: Ouro / Ferro / Cobre / Níquel + cotações  
4. Cadastro de lote: mídia (até 5 fotos + 1 vídeo), teor (minério), cobre total/solúvel  
5. Serviços (tipos de prestador)  
6. Negociar → Minera Chat (anti-golpe)  
7. Minera Bank  
8. CTA + link Pages  

## O que NÃO mostrar

- Dados de usuários de teste / e-mails de terceiros  
- Chaves Pix reais, documentos, CPF, telefone  
- WhatsApp como canal de negociação do produto  
- Painel admin interno (salvo menção breve “gestão da plataforma”)
